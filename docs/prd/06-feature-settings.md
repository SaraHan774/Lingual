# 06 — Feature: Settings (설정)

[← 목차로](../../PRD.md) · **status: shipped (read-only v0.1)**

## Goal

v0.1에서 Settings는 **사용자에게 앱의 동작 원리를 안내**하는 읽기 전용 화면이다. 번역·TTS의 동작 방식과 앱 정보를 명시함으로써 "왜 처음엔 느린가(모델 다운로드)", "왜 오프라인에서 되는가"라는 질문에 선제적으로 답한다.

## Non-Goals (v0.1)

- 테마 변경(라이트/다크) — 시스템 설정 추종.
- 언어 모델 다운로드 관리(용량 표시/수동 삭제) — Phase 2.
- 데이터 내보내기/가져오기 — Phase 2.
- 계정·로그인 — 전체 out of scope.

## 현재 화면 구성 (`SettingsScreen.kt`)

1. **번역 엔진** 섹션
   - "현재 엔진: Google ML Kit (온디바이스, 오프라인)"
   - "번역 모델은 최초 사용 시 자동으로 다운로드됩니다 (언어당 약 30MB)."
2. **TTS** 섹션
   - "Android 시스템의 TextToSpeech를 사용합니다. 지원 언어는 기기 설정에 따릅니다."
3. **앱 정보** 섹션
   - "Lingual · v0.1 MVP"
   - "한국어, English, 日本語, 中文 간 일기 번역 및 학습 앱"

## Acceptance Criteria

- [x] 4개 섹션 헤더가 primary 색상으로 강조되어 시각적 계층이 분명하다.
- [x] 긴 디바이스에서도 스크롤이 자연스럽고 잘림이 없다.
- [x] v0.1에서는 어떤 항목도 사용자 입력을 받지 않는다 (읽기 전용).

## Phase 2 후보 (사용자 편집 가능 설정)

| 항목 | 설명 | 우선순위 |
|------|------|---------|
| TTS 속도/피치 | 언어별 or 전역 슬라이더 | 중 |
| 번역 모델 관리 | 언어쌍별 용량 표시, 수동 재다운로드/삭제 | 중 |
| 기본 원문 언어 | 일기 작성 시 기본 선택 언어 | 높 |
| 데이터 내보내기 | JSON 백업 파일 생성 (일기 + 번역 + 단어) | 중 |
| 데이터 가져오기 | JSON 복원. 충돌 시 병합 전략 필요 | 중 |
| 앱 잠금 | 생체인증 또는 PIN으로 일기 보호 | 높 |
| 개인정보 처리방침/오픈소스 라이선스 | 링크/화면 | Play Store 출시 전 필수 |

## Open Questions

- **앱 잠금 범위**: 앱 전체를 잠글지, 일기 상세만 잠글지. 후자는 UX가 부자연스러움.
- **기본 원문 언어 기본값**: 시스템 Locale 추종 vs 마지막 사용 언어 기억. 학습 앱 특성상 후자가 더 유용할 수 있음.
- **데이터 내보내기 포맷**: 자체 JSON 스키마 vs 표준(SRS 포맷 호환?). 초기에는 자체 스키마가 단순.
