# 01 — Overview & Vision

[← 목차로](../../PRD.md)

## Product Vision

Lingual은 **"일기를 쓰면 4개 언어가 함께 자라는 앱"** 이다. 다국어 학습자가 매일 모국어 또는 목표 언어로 일기를 쓰면, 앱은 나머지 3개 언어로 온디바이스 번역하고 음성으로 들려주며, 선택한 단어를 플래시카드로 축적해 장기 기억을 돕는다.

**왜 온디바이스인가.** 일기는 사적 기록이다. 번역을 위해 원문이 외부 서버로 전송되면 심리적 저항이 생긴다. 최초 모델 다운로드 이후 모든 번역이 네트워크 없이 동작하는 것이 Lingual의 차별점이자 타협 불가능한 원칙이다.

## 타겟 페르소나

| Persona | 배경 | Pain Point | Lingual로 얻는 가치 |
|---------|------|-----------|------|
| **영어 유학생 민지 (KO→EN)** | 한국에서 자라 미국에서 석사 중. 영어로 일기 쓰려 하면 막힘. | 사전을 찾으며 쓰다 보면 흐름이 끊긴다. | 한국어로 쓰고 영어 번역을 즉시 비교하며 표현을 체득. |
| **일본어 덕후 하루 (EN↔JA)** | 미국 직장인, 일본어 JLPT N3 준비. | 학습 앱은 문장 단위가 없고 일기 앱은 번역이 없음. | 일기라는 맥락 있는 문장으로 학습. |
| **중국 출신 주재원 웨이 (ZH→KO)** | 서울 근무 3년차. 한국어 구어 실력은 있으나 문어 약함. | 한국어로 쓰면 어색함이 많음. | 중국어로 쓰고 자연스러운 한국어 번역을 학습 소스로. |

## Scope

### In Scope (v0.1 MVP — 현재)

- 4개 언어(KO/EN/JA/ZH) 간 일기 번역
- 단일 디바이스, 오프라인 우선 동작
- 단어 카드 **수동** 추가 및 학습
- TTS 재생(기기 내장 음성)
- Android 단일 플랫폼(minSdk 28, targetSdk 35)

### Out of Scope (v0.1)

- 계정/클라우드 동기화
- 문법 교정·작문 피드백
- 친구·소셜·공유 기능
- iOS·웹 클라이언트
- 유료 구독 / 인앱 결제
- 자동 단어 추출(→ `08-roadmap.md`의 Phase 2)

## 성공 지표 (Success Metrics)

이 지표들은 v1.0 Play Store 출시 이후 적용된다. v0.1 MVP 단계에서는 내부 검증용으로만 기록.

| 영역 | 지표 | 목표 (v1.0 출시 +90일) |
|------|------|------|
| Activation | 설치 후 첫 일기 작성률 | 60% |
| Retention | D7 리텐션 | 25% |
| Depth | 주당 평균 작성 일기 수 (활성 사용자) | 3편 |
| Learning | 단어 카드 평균 숙련도 증가율 | 월 +0.5 (스케일 0–3) |
| Quality | 번역 ERROR 상태 비율 | <2% |

## 비기능 요구 요약 (상세는 `07-architecture.md`)

- **오프라인 우선**: 번역·TTS 모두 네트워크 없이 동작. 최초 모델 다운로드만 예외.
- **프라이버시**: 원문·번역·단어는 로컬 Room DB(`lingual.db`)에만 저장. 외부 전송 없음.
- **응답성**: 일기 저장 후 번역 PENDING 상태 표시는 <500ms. 모델 로드 후 단문(<100자) 번역 <3s.
- **언어 감수성**: 모든 UI 문자열은 4개 언어 네이티브 표기를 사용 (`한국어 · English · 日本語 · 中文`).

## Acceptance Criteria (MVP 전체 관점)

- [x] 사용자가 4개 언어 중 하나를 선택해 일기를 저장하면, 다른 3개 언어의 Translation 레코드가 PENDING으로 즉시 생성된다.
- [x] 각 번역이 완료되는 대로 해당 언어 탭이 스피너 → 텍스트로 전환된다.
- [x] 모든 번역 및 일기 데이터가 앱 재실행 후에도 유지된다.
- [x] 4개 언어 각각에서 TTS 재생이 가능하며, 기기가 해당 언어 TTS 데이터를 미설치 시 명시적 에러 메시지가 노출된다.
- [ ] Play Store 공개 시 필요한 개인정보 처리방침·스토어 리스팅 텍스트가 준비되어 있다. (→ roadmap)

## Open Questions

- **언어 확장 기준**: 스페인어·프랑스어 추가 요청이 들어오면 어떤 기준(사용자 수, ML Kit 지원 여부)으로 수락할 것인가?
- **일기 길이 제한**: 현재 무제한. ML Kit 번역 지연·품질 관점에서 상한이 필요한가?
- **데이터 이식성**: 사용자가 기기를 바꿀 때 로컬 DB를 수동 내보내기/가져오기할 수단을 제공할 것인가? (클라우드 동기화는 여전히 out of scope)
