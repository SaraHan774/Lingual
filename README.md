# 🥃 SpiritScribe

**Distill Your Taste** - Personal whiskey tasting note app for enthusiasts.

## Features
- 📝 Whiskey collection management
- 🍯 Detailed tasting notes
- 🎯 Flavor profile analysis
- 📊 Taste evolution tracking
- 🔍 Smart search & filtering

## Tech Stack
Kotlin • Jetpack Compose • Room • Hilt • Firebase

## Build
```bash
./gradlew assembleDebug
./deploy.sh debug "Release notes"
```
